    How it works

    The calculator searches whole-number combinations. Where prices are supplied it chooses the lowest total cost; ties prefer lower surplus, then fewer packs. If no prices are supplied, it calculates the smallest number of packs for the first valid product.

    This is purchase optimisation, not a construction recommendation. Include any project-specific waste allowance in the target before optimising.
